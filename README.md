# Operating-System-Projects

Projects created for an Operating Systems course.

## Overview

This repository contains two major projects:

### 1. Operating Scheduler Simulator
A simulation of an operating system scheduler that manages process execution based on priority and scheduling rules.

### 2. Page Table Lookup & TLB Simulator
A functional page‑table lookup system with a working Translation Lookaside Buffer (TLB).  
Includes an example input file demonstrating address translation behavior.
